# Development Rules

- One Sprint = One Goal.
- Full file when modifying files.
- Run `npm run lint` and `npm run build`.
- Ask for missing files. Do not guess.
- Refactor only with clear goal.
- Update PROJECT_HANDOFF if architecture/status changes.
