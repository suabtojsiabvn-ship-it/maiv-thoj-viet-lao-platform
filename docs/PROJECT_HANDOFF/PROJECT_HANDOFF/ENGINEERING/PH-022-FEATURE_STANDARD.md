# Feature Standard

A feature is an independent business capability.

## Rules
- Entry file exports public feature.
- Components render only.
- Hook creates ViewModel.
- `feature/data` is metadata only.
- Business copy belongs to content or dictionary.

## Done Checklist
- Entry exists.
- index.ts exports public API.
- Hook/types exist if needed.
- No hardcoded multilingual copy.
- Build PASS.
- Lint PASS.
