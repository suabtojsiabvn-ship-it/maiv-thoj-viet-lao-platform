# Glossary

Feature: independent business capability.
Content Layer: business content under content/.
Dictionary: locale-specific multilingual text.
Metadata: presentation data like image, icon, order, slug.
ViewModel: data prepared by hook for UI.
Production Ready: implementation, content, localization, SEO and build are acceptable.
Reality Check: truthful status assessment.
PROJECT_HANDOFF: SSOT for handoff/current project state.
