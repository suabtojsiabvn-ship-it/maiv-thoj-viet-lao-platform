# Project DNA

## This Project Is Not
- A simple dental clinic website.
- A disposable landing page.
- A generic travel blog.
- A one-language brochure.

## This Project Is
- International Medical Tourism Platform.
- Hmong-first multilingual healthcare journey platform.
- Medical concierge system.
- Patient journey platform.
- Future content, booking and CRM platform.

## Core Belief
A patient traveling internationally for dental treatment needs more than clinical information. They need trust, language support, guidance, travel assistance and aftercare.
