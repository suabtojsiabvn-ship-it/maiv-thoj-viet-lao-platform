# Executive Summary

Maiv Thoj Viet Lao Platform is a multilingual international medical tourism platform built with Next.js, TypeScript and feature-based architecture. It connects overseas patients, especially the Hmong community, with trusted dental and healthcare providers in Vietnam through a complete patient journey: consultation, communication, airport pickup, accommodation, clinic visit, treatment, travel memory and aftercare.

## Technical State
The project has completed its foundation using feature-based modules, content layer, locale dictionaries, shared UI, shared content components, metadata separation and hook ViewModel pattern.

## Business State
The platform is an International Medical & Beauty Concierge Platform, Dental Tourism Platform, Hmong-first international patient support platform, and future medical ecosystem foundation.
